# Crônica do Matador do Rei

## 📖 Sobre o Projeto

Este repositório contém um site desenvolvido com **HTML**, **CSS** e **JavaScript**, cujo objetivo é apresentar informações sobre a saga **Crônica do Matador do Rei**, uma série de fantasia escrita por Patrick Rothfuss e amplamente reconhecida pela comunidade de leitores.

O site reúne conteúdos sobre os livros da série, seus personagens e o autor, proporcionando uma experiência simples e informativa para os visitantes.

---

## 🎯 Objetivo

Desenvolver um site estático para praticar conceitos de desenvolvimento web, organização de projetos e trabalho colaborativo utilizando Git e GitHub.

---

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

## 📂 Estrutura do Projeto

```text
├── index.html
├── personagens.html
├── livro1.html
├── livro2.html
├── autor.html
├── main.js
└── style.css
```

### Descrição das páginas

- **index.html** – Página inicial do projeto.
- **personagens.html** – Informações sobre os principais personagens da saga.
- **livro1.html** – Conteúdo referente ao primeiro livro.
- **livro2.html** – Conteúdo referente ao segundo livro.
- **autor.html** – Informações sobre o autor Patrick Rothfuss.
- **main.js** – Scripts JavaScript do site.
- **style.css** – Estilização das páginas.
